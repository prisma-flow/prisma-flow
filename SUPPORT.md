# Support

Use the right channel so maintainers and contributors can respond efficiently.

## Questions and usage help

Use GitHub Discussions for setup help, usage questions, workflow guidance, and troubleshooting that is not clearly a product bug:

https://github.com/prisma-flow/prisma-flow/discussions

Use the **Q&A** category when you need an answer. Please search existing discussions first and redact database URLs, credentials, private schema details, and migration SQL before posting.

## Ideas and design discussions

Use GitHub Discussions for early feature ideas, design proposals, integrations, and broader project direction:

https://github.com/prisma-flow/prisma-flow/discussions

Once an idea is concrete and actionable, maintainers may promote it to a GitHub issue.

## Bugs and actionable work

Use GitHub Issues for reproducible bugs and concrete implementation tasks. Include reproduction steps, PrismaFlow and Prisma versions, database provider, operating system, and redacted output where relevant:

https://github.com/prisma-flow/prisma-flow/issues/new/choose

## Security

Do not open public issues or discussions for suspected vulnerabilities. Use GitHub private vulnerability reporting:

https://github.com/prisma-flow/prisma-flow/security/advisories/new

Redact database URLs, tokens, credentials, schema details, and private migration SQL from all public reports.
